# 文字版录屏（3–5 分钟）

> 这不是手写的剧本，而是**对真实链路的抓取**：下面的台词、指令、打断与错误，全部来自
> `bun /tmp/demo-run.ts` 对线上同一套代码的实跑（官方 `deepseek-chat` 导演、阿里百炼真流式
> 识别、Edge 原生 TTS）。视频录屏（真人对着麦克风）尚未录制；本文件是它的可核对替代物：
> 每一段都给出「屏幕上发生什么 + 她说什么 + 事件流里的指令 + 实测延迟」。

---

## 0:00–0:20　开场

- **画面**：咖啡店夜场景（`cafe_night`），角色待机，呼吸与眨眼在动；左下角状态条显示
  「Mock 导演」或「真模型」（取决于 URL 是否带 `?director=live`）。
- **口播**：72 小时作业，实时互动场景。一条命令 `bun install && bun run dev` 起前后端；
  不带任何密钥也能完整跑通（Mock 导演），带 `?director=live` 走真模型。
- **要点**：默认零密钥是刻意的，评审不该因为配额或网络看不到东西。

## 0:20–1:10　第一轮：文字互动 + 四态

- **操作**：输入「你今晚一个人？」
- **台词**（实测）：`一个人。本来约了人，没说什么事。你呢，也是躲雨，还是在等人？`
- **指令**（实测）：`emotion=neutral` → `pose=hold_cup` → `emotion=amused`
- **屏幕上**：待机（呼吸）→ 思考（视线偏移、画面降饱和）→ 说话（口型 + 字幕逐字推进）
- **延迟**：首字 **1381ms** / 整轮 1735ms
- **口播**：字幕是流式增量，不是整段铺满。

## 1:10–1:50　由对话内容触发的视觉事件

- **操作**：输入「外面还在下雨吗？」
- **台词**（实测）：`还在下。玻璃上全是水，看不清街对面。反正我也没打算现在走。`
- **指令**（实测）：`pose=glance_window` → `vfx=rain_light`
- **屏幕上**：她转向窗户，雨势变重
- **延迟**：首字 **966ms** / 整轮 1326ms
- **口播**：这些不是定时器轮播，是这句话命中 beat 才触发；换一句无关的话不会出现。

## 1:50–2:30　场景切换（第一处）

- **操作**：输入「是不是该打烊了」
- **台词**（实测）：`看样子是。灯都关了一半了。我等到最后一口咖啡吧，人没来就算了。`
- **指令**（实测）：**`scene=cafe_closing`** / `emotion=sad` / `action=sigh`
- **屏幕上**：整个场景从「营业中」切到「打烊」——灯光变暗，桌椅收起，她叹了一口气
- **延迟**：首字 **1031ms** / 整轮 1411ms

## 2:30–3:00　场景切换（第二处）

- **操作**：输入「我看看窗外」
- **台词**（实测）：`看吧。雨比刚才还大，路灯都糊成一团。这种天，谁迟到都不奇怪。`
- **指令**（实测）：**`scene=window_rain`** / `pose=glance_window` / `vfx=rain_heavy` / `emotion=sad`
- **屏幕上**：切到雨窗视角，玻璃上全是水痕，雨势加重
- **延迟**：首字 **922ms** / 整轮 1333ms
- **口播**：两处场景切换都是对话内容驱动的，不是预设播放顺序。

## 3:00–3:40　★ 说话中打断

- **操作**：她正在说话时按「按住说话」（等同 Esc / 打断按钮，三处同一套判据）。
- **实测结果**：`turn.end.interrupted = true`，**打断之后仍收到的 `text.delta = 0`**
- **屏幕上**：语音立刻停、字幕不再增长、动作与镜头停在当前帧、状态切回倾听
- **口播**：`epoch + turnId` 双闸门丢掉旧轮事件，所以「迟到的响应」不会把画面拉回去；
  打断判据还包含「音频真的还在响」这一条，`turn.end` 之后缓冲仍在播的窗口里也能打断。

## 3:40–4:20　★ 失败与降级（真实发生，不是演的）

- **操作**：输入「我们去看海吧」
- **实测结果**：`error: 上游返回的内容无法解析为 JSON`，`turn.end` 仍然正常收尾（907ms）
- **屏幕上**：**红色错误提示条**说明「本轮台词可能被截断或夹带指令原文」，可重试；文字输入仍可用
- **口播**：这是护栏在工作——模型违约时宁可报错，也不把脏内容吐到字幕里。
  另外：海边场景目前**没有渲染器**（`sky/sea/shore` 三层未绘制），所以它不会假装切过去，
  而是用台词的边界应付；真支持它需要先补渲染器（写进 README「再给两周」）。

## 4:20–4:50　语音链路（真人麦克风，需本人操作）

- **操作**：点麦克风 → 允许权限 → 说一句带句号或问号的中文 → **不要点关闭麦克风**
- **屏幕上**：约 0.45 秒后开始新一轮（句末标点触发自适应收尾）；`?obs=1` 抽屉里能看到
  `stt:auto-finish quietMs=450`，以及首事件 / 模型首字 / 首个音频分片 / 真正出声 / 整轮五段耗时
- **口播**：识别走服务端代理的阿里百炼真流式，边说边出字；合成是 Edge 原生 WS（热连接 287ms）。

## 4:50–5:00　收尾

- 扫一遍 README 的目录：系统结构 / 打断是怎么做对的 / 角色与场景指令 / 取舍 / 已知问题 /
  投入时间 / 再给两周怎么演进。

## 这份文件不能替代什么

- **听感**：文字记录不出「她的声音好不好听、打断是否干脆」，这必须真人听。
- **视觉**：角色像不像人、场景切换是否突兀，只能看。
- 所以正式交付仍需要一段真人录屏；本文件的作用是让评审在**没有视频**时也能逐条核对行为。
