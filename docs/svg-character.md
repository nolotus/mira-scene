### 指令覆盖（改造前）

- `blink`：眼睑闭合，已实现。
- `hair_tuck`：前景替身手臂淡入 / 伸向发夹，垂臂淡出，偏头、发夹、发丝、视线、肩和衣摆都有动画；并非空实现，但存在替身贴图感与姿态覆盖。
- `sigh`：肩胸起伏、低头、下颌、衣摆；已实现，肩和下颌覆盖原姿态。
- `shiver`：肩、头、双臂、眼形、衣摆；已实现，肩臂覆盖原姿态。
- `look_back`：头、肩、颈；已实现，颈肩覆盖原姿态。
- `nod`：头、肩；已实现。
- `startle`：头、肩、躯干、双臂、下颌、眼形、衣摆；已实现。
- `stand`：中性姿态。
- `lean_in`：局部颈前伸、压肩与头部补偿已有，但同时叠加整体平移 / 缩放。
- `turn_away`：已有整体 Y 轴侧转、头部补偿、阴影；视线未由 pose 直接驱动。
- `glance_window`：已有侧转、偏头、阴影，但缺少对应瞳孔方向。
- `hold_cup`：有姿态参数，但关键语义“手握杯”未实现，仅杯子显现。

没有完全未消费的 Action；薄弱项是握杯语义、望窗视线及姿态 / 动作层的 transform 冲突。场景 / 镜头 / 环境 directive 不属于本次改动范围。

## 本次实现

- POSE_RIG 为每种姿势增加视线和肘折叠参数，ACT_DUR 用 Record<Action, number> 编译期检查完整性。
- pose 不再驱动整个人的平移、旋转和缩放；保留 status 原有走位。姿态通过头、颈、肩、躯干和手臂表达。
- 颈、肩、躯干、双臂、下颌采用“姿态父层 → 动作子层”，动作结束回到已有姿态，不覆盖其 transform。
- 拆分双侧上臂、前臂、手，握杯前臂绕肘旋转 -65°；杯壁前方增加手指接触遮挡层。姿势过渡约 900ms，杯 / 手指淡入 620ms。
- 胸腔局部呼吸替代整个人缩放；侧发随头部动作，独立保留低幅度摆动。
- 杯中物独立分层，低幅度水面起伏与 shiver 涟动。
- 保留随机眨眼、字幕驱动口型及 reduced-motion；闭口相位重新显示情绪嘴。说话点头受 mouthDrive 控制，与实际发声仲裁一致。
- 不修改协议、导演提示词、场景、依赖或舞台文件。
